Secure `goldenhops.be` from SQLi attacks.

The Goldenhops website was clearly not secured against one of the most common vulnerabilities in the website landscape. Let’s quickly **solve this issue by implementing FortiWeb**.

<br>

Navigate to **FortiWeb** using **Chrome** on the **IT workstation** in Cloudshare. <a href="Credentials" target="_blank">**credentials**</a>

Credentials can be found on the Credentials tab on you CTFd platform.


Objective: Use **FortiWeb** to **block** the **SQL injection exploitation** by configuring a **Web Protection Policy**

To achieve this, you should create a **Signature Policy** to detect SQLi and enforce it using a **Web Protection Profile**.

### Configure Web protection policy

<br>

<div class="red">

Please, do not remove existing configuration. Only modify existing configuration when explicitly described in the steps bellow.

</div>

<br>

1. Create signature for SQLi.

    Go to `Web Protection` → `Known Attacks` → `Signatures` → Click `Create New`.

    <img src="/images/sql_defense_hint_1.png" style="max-width: 100%; height: auto;">
    
    

1. Give the **Signature policy** a name and enable **SQL Injection (Extended)** otherwise the traffic will just pass with normal SQLi.

    <img src="/images/sql_defense_hint_2.png" alt="Web Protection Signature Block SQL" style="max-width: 100%; height: auto;">


1. Now create a Web Protection Profile to add to the Server Policy. 

    
    Go to `Policy` → `Web Protection Profile` → Click `Create New`

    <img src="/images/sql_defense_hint_3.png" alt="Web Protection Profile" style="max-width: 100%; height: auto;">
    

1. Enter the name for the **Profile**:`block_sql`, and select the newly created **Signature**: `SQL Block`


    <img src="/images/sql_defense_hint_4.png" alt="Web Protection Profile" style="max-width: 100%; height: auto;">


1. **Apply** the Profile to the Server Policy by going to `Policy` → `Server Policy` → `access` **Server Policy** and adding the profile to the policy and clicking **OK**.

    <img src="/images/sql_defense_hint_5.png" alt="Web Policy" style="max-width: 100%; height: auto;">
